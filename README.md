# Tajamar GenAI Tasks

## Description
Tajamar GenAI Tasks is a comprehensive repository designed to house various tasks and implementations related to Generative AI. This project aims to facilitate the exploration and usage of generative models through structured tasks and practical examples.

## Installation Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/adnanhamidoun/tajamar-genai-tasks.git
   ```
2. Navigate to the project directory:
   ```bash
   cd tajamar-genai-tasks
   ```
3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
