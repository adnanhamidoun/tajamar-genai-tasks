Capa de Servicios (Lógica de Negocio)
SERVICIOS
🧠
RAGService
Motor de Retrieval-Augmented Generation. Orquesta la ingesta de documentos, la búsqueda híbrida (BM25 + vectores), y la generación de respuestas con contexto.
Hybrid Search Top-K 50 OData Filters LangChain
📦
StorageService
Gestión de archivos PDF en Azure Blob Storage. Upload, listado, borrado individual y limpieza masiva con preservación selectiva.
Azure Blob SDK Prefixed Blobs Selective Delete
👤
AssistantService
CRUD de asistentes con generación automática de System Prompts vía Azure OpenAI. Protección del asistente técnico (UUID inmutable).
UUID Fijo Prompt Gen SQLAlchemy 2.0
▼
SDK Calls · Async I/O
Capa de Datos y Servicios Azure
AZURE
🗃️
Azure SQL Database
Base de datos relacional con tablas assistants y chat_messages. Relación 1:N con cascade delete. Acceso async vía SQLAlchemy 2.0 + aioodbc.
SQLAlchemy 2.0 Async Sessions Mapped Types
📂
Azure Blob Storage
Almacenamiento de archivos PDF originales. Estructura de carpetas por asistente: assistants/{id}/{uuid}-filename.pdf
Containers Prefix Listing UUID Naming
🔎
Azure AI Search
Índice vectorial con campos content_vector, assistant_id, filename. Búsqueda híbrida BM25 + semántica con filtros OData de aislamiento.
Vector Index BM25 + kNN OData Filters
🤖
Azure OpenAI
Modelos GPT-4o para chat con streaming y text-embedding-ada-002 para generación de vectores. Acceso vía LangChain SDK.
GPT-4o Embeddings ada-002 Streaming SSE
